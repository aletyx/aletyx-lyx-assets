# aletyx-lyx-assets

Public images for the [Aletyx Lyx](https://marketplace.visualstudio.com/items?itemName=aletyx.aletyx-lyx) VS Code extension's Marketplace page.

The extension's source repository is private, and the Marketplace page (and VS Code's view of an extension that isn't installed) can only load images from a public URL. The Lyx README links to the files in `readme/` here.

Change these together with `media/readme/` in the Lyx repository.
