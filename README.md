# aletyx-lyx-assets

Public images and the privacy notice for the [Aletyx Lyx](https://marketplace.visualstudio.com/items?itemName=aletyx.aletyx-lyx) VS Code extension's Marketplace page.

The extension's source repository is private, and the Marketplace page (and VS Code's view of an extension that isn't installed) can only load images from a public URL. The Lyx README links to the files in `readme/` here.

It also holds `PRIVACY.md`, which the README links to. This repository is the only copy of these files: change them here.
